CREATION API REST avec Express de Node JS
API CRUD avec un architecture complet (Model, Middleware, Controller, Routes)
Utilisation d'une base de donnée PostgreSQL
* Configuration des environnement de dev dans ./config
* Connexion BD et création des requête dynamique dans ./config/db.js
* Création des modèle + requête CRUD vers DB
* Gestions des validation de donnée côté server, gestion erreurs, création fonction asynchrone dynamique dans ./middleware => valider, async-handler et erreurs
* Création des controllers pour rélier la requête HTTP avec SQL et donne un res en JSON
* Création des routes pour relier les validations d'abord, puis vers controller
